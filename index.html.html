🔥 Cloud Sync Setup

This connects the app to a free Google Firebase database so your data is shared across all phones, tablets, and computers. One-time setup, takes ~5 minutes.

Step 1 — Create a Firebase Project

Open this link in a new tab:

Open Firebase Console ↗

Sign in with any Google account, then click "Create a project". Name it whatever you want (e.g. "job-tracker"). You can turn off Google Analytics when asked — it's not needed.

Step 2 — Create the Database

Once your project is created, look at the left sidebar and click "Build", then "Realtime Database".

Click the "Create Database" button. Pick any location (default is fine). When it asks about security rules, choose "Start in test mode" and click Enable.

Step 3 — Get Your Config Code

Look at the very top of the left sidebar — you'll see "Project Overview". Right next to that text there's a tiny ⚙ gear icon. Click it and a dropdown will appear — select "Project settings".

Or just click this direct link after creating your project:

Open Project Settings directly ↗

Scroll all the way down to "Your apps". If you don't see any apps listed, click the web icon that looks like this: </>

Give it any name (e.g. "tracker"), click "Register app".

You'll see a code block. Find the part that looks like this and copy it:

const firebaseConfig = { apiKey: "AIzaSyB...............", authDomain: "my-tracker-12345.firebaseapp.com", databaseURL: "https://my-tracker-12345-default-rtdb.firebaseio.com", projectId: "my-tracker-12345", storageBucket: "my-tracker-12345.appspot.com", messagingSenderId: "123456789012", appId: "1:123456789012:web:abc123def456" };

Select everything from the opening { to the closing } (including the curly braces). Right-click → Copy, or press Ctrl+C / Cmd+C.

Step 4 — Paste It Here

Click in the box below, then paste (Ctrl+V / Cmd+V / long-press → Paste on phone):

You only paste this once per device. To change it later, go to ⚙ Manage → 🔥 Firebase Settings.
